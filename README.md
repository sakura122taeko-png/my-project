# 管理者教育スライド集

管理者教育で使うスライドを、テーマ別に整理して保管するリポジトリです。

## フォルダ構成

| フォルダ | 内容 |
| --- | --- |
| `01_マネジメント基礎` | 管理者の役割・責任、組織の目標と方針の理解、管理者としての心構え |
| `02_リーダーシップ` | リーダーシップ理論、チームづくり、意思決定、動機づけ |
| `03_コミュニケーション` | 報連相、会議運営、1on1ミーティング、傾聴とフィードバック |
| `04_人材育成・コーチング` | OJT、コーチング、部下の育成計画、指導方法 |
| `05_目標管理・人事評価` | 目標設定（MBO・OKR）、評価の基準と面談、評価エラーの防ぎ方 |
| `06_労務管理・コンプライアンス` | 労働時間管理、労働関係法令、就業規則、情報管理、コンプライアンス |
| `07_ハラスメント防止・メンタルヘルス` | ハラスメントの定義と対応、ラインケア、ストレスチェック |
| `08_業務改善・問題解決` | 問題解決の手法、PDCA、業務の効率化、リスク管理 |
| `99_テンプレート` | スライドの共通テンプレート、ロゴやデザイン素材 |
| `_アーカイブ` | 使わなくなった旧版のスライド（削除せずにここへ移動） |

テーマが増えたら `09_〇〇` のように番号を続けてフォルダを追加し、この表にも1行追加してください。

## ファイル名のルール

```
連番_タイトル_vバージョン_更新日.拡張子
```

例:

- `01_管理者の役割と責任_v1_20261030.pptx`
- `02_1on1ミーティングの進め方_v2_20261115.pdf`

- **連番**: フォルダ内で受講してほしい順番（01, 02, …）
- **バージョン**: 内容を改訂したら v1 → v2 と上げる
- **更新日**: `YYYYMMDD` 形式
- 編集用ファイル（.pptx）と配布用ファイル（.pdf）は同じ名前で並べて置く
- 古い版は削除せず `_アーカイブ` へ移動する
